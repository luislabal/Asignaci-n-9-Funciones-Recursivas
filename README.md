Asignacion 9 Funciones Recursivas

#Características: El siguiente proyecto contiene cinco ejercicios desarrollados en dos versiones ya sea una iterativa u otra recursiva.
El objetivo de ka msima es practicar la identificación del caso base, para eso utilizamos la formulación del caso recursivo, y comparamos 
la eficiencia entre ambos enfoques. De igual manera, los ejercicios implementan el uso de funciones recursivas aplicadas en diferentes contextos 
y tambien nos muestran cómo la recursión puede simplificar la lógica de algunos problemas.

Funcion 1: Identificar y aplicar el caso base y el caso recursivo en diferentes problemas.
Funcion 2: Comparar la eficiencia entre las versiones iterativas y recursivas.
Funcion 3: Comprender cuándo la recursión es la opción más natural para resolver un problema.

#Ejercicios realizados:
1.Suma de elementos de un arreglo: Calcula la suma total de los elementos de un arreglo.
2.Contar ocurrencias: Cuenta cuántas veces aparece un valor en un arreglo.
3.Imprimir archivos y carpetas: Lista todos los archivos y subcarpetas de un directorio.
4.Invertir una cadena: Devuelve una cadena invertida.
5.Número palíndromo: Determina si un número entero es palíndromo.
